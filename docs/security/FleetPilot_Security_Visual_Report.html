New Security Features Added

Two-Factor Authentication

TOTP Support New
Google Authenticator, Authy, Microsoft Authenticator — any RFC 6238 compatible app. QR code generated automatically during setup.
YubiKey OTP New
Hardware security key support. YubiKey OTP tokens can be registered and used as a second factor.
Backup Codes New
One-time emergency backup codes generated during 2FA setup. Stored securely as hashed values.
Seamless Login Flow
After successful password auth, users with 2FA enabled are redirected to the verification screen before accessing the dashboard.

Other Security Improvements

Rate Limiting Tuned
Local network IPs (192.168.x.x) are whitelisted to prevent accidental self-lockout. External IPs are still protected.
CSRF Protection Fixed
A bug where CSRF was re-enabled after each request on exempt routes was identified and patched.
Input Sanitization
All form inputs now use markupsafe.escape() to prevent reflected XSS attacks across all templates.
OpenSSL Compatibility
Flask and Werkzeug upgraded to versions fully compatible with OpenSSL 3.0 on Debian 12, resolving the login 500 error.
