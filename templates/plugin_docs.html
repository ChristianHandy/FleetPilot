{{ _('Overview') }}

FleetPilot plugins are plain Python files placed in the addons/ directory. They are loaded automatically at startup. A plugin can inject HTML into any part of the dashboard, register Flask routes, run background threads, or react to system events (like a completed update run).

What plugins CAN do
  • {{ _('Add widgets to the dashboard') }}
  • {{ _('Add buttons to host cards') }}
  • {{ _('Add tabs to host detail view') }}
  • {{ _('Add sidebar navigation links') }}
  • {{ _('React to update events') }}
  • {{ _('Add Flask routes / pages') }}
  • {{ _('Run background threads') }}
  • {{ _('Send external notifications') }}
Security notes
  • {{ _('Plugins run with full app privileges') }}
  • {{ _('Only install from trusted sources') }}
  • {{ _('Admin role required to install') }}
  • {{ _('Restart required after install') }}
  • {{ _('Never store secrets in plugin code') }}

{{ _('Plugin Structure') }}

Every plugin is a single .py file with two optional parts:

# my_plugin.py
# ─────────────────────────────────────────────────────────────────────────────
# Part 1: addon_meta — describes the plugin and registers hooks
# ─────────────────────────────────────────────────────────────────────────────
addon_meta = {
    # Required
    "name":        "My Plugin",
    "version":     "1.0.0",
    "author":      "Your Name",
    "description": "Short description shown in the Plugin Manager",
    "scope":       "global",  # global | disks | hosts | dashboard | scanner

    # Optional: hook registrations (see Hook Reference below)
    "dashboard_widget": lambda hosts, stats: "<div>...</div>",
    "sidebar_link":     lambda: {"label": "My Page", "url": "/my_page", "icon": ""},
}

# ─────────────────────────────────────────────────────────────────────────────
# Part 2: register() — called once at startup with the Flask app and disk core
# ─────────────────────────────────────────────────────────────────────────────
def register(app, core):
    """Optional. Use to add routes, start threads, etc."""
    from flask import Blueprint
    bp = Blueprint("my_plugin", __name__)

    @bp.route("/my_page")
    def my_page():
        return "<h1>My Plugin Page</h1>"

    app.register_blueprint(bp)
    print("[my_plugin] loaded")

Payloads

  • hosts, stats (dashboard_widget): each entry in hosts is a host dict with {"name", "host", "user", "status", ...} where status is "online", "offline" or "unknown" from the last reachability check; stats is {"total", "online", "offline", "unknown"}.
  • host (update_pre, update_post): {"name", "host", "user"} — the display name, the address and the SSH user of the host being updated.
  • result (update_post): {"success", "packages_updated", "name", "host", "error"}. success is a bool, error the joined error text (empty when the update worked), and packages_updated is 0: FleetPilot does not parse the package managers' output for a count.
  • notification:
    • event="new_version_available", data={"type", "version", "description", "url"} — when a newer release or commit appears (once per version, not on every 24-hour check).
    • event="update_report", data={"hosts_status", "history"} — when a scheduled email update report runs (email_notifier.send_update_report).
    • event="update_error", data={"host", "error"} — when a host update error notification is sent (email_notifier.send_error_notification).
    • event in notify.EVENTS ("smart", "security", "backup", "router", "vulnerability", or any event passed to notify.send), data={"title", "message", "level"} — when notify.send() dispatches a message.
  • Hooks run after the update result is stored, and an exception raised inside a hook is logged instead of propagated: a notification can never break the update it reports on.

{{ _('Adding Flask Routes') }}

def register(app, core):
    from flask import Blueprint, render_template, jsonify, request, session
    from functools import wraps

    bp = Blueprint("my_plugin", __name__, url_prefix="/my_plugin")

    # Re-use the existing login_required decorator
    def login_required(f):
        @wraps(f)
        def decorated(*args, **kwargs):
            if not session.get("user_id"):
                from flask import redirect, url_for
                return redirect(url_for("login"))
            return f(*args, **kwargs)
        return decorated

    @bp.route("/")
    @login_required
    def index():
        return render_template("addons/my_plugin.html")

    @bp.route("/api/data")
    @login_required
    def api_data():
        return jsonify({"status": "ok", "data": []})

    app.register_blueprint(bp)

{{ _('Security Guidelines') }}

  • {{ _('Plugins run with full application privileges') }} — treat them like application code, not user content.
  • {{ _('Only install plugins from sources you trust completely.') }}
  • {{ _('Never hardcode API keys, passwords, or tokens in plugin files. Use environment variables instead.') }}
  • {{ _('If your plugin makes outbound HTTP requests, validate all URLs and handle errors gracefully.') }}
  • {{ _('Sanitize any user input before using it in shell commands or SQL queries.') }}
  • Use Flask's login_required pattern on all routes your plugin adds.
