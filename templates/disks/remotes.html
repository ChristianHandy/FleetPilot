Setup Instructions

{{ _('To manage disks on remote systems, you need to:') }}

  1. {{ _('Add a remote system') }} using the form above with hostname/IP, SSH port, and the SSH account used on that host.
  2. {{ _('Configure SSH key authentication') }} - Use the configured remote SSH account. For Proxmox, this is normally root.
  3. {{ _('Ensure sudo privileges') }} - The remote user needs passwordless sudo access for disk commands: 
    # Add to /etc/sudoers.d/disk-tools on remote system
username ALL=(ALL) NOPASSWD: /usr/bin/lsblk, /usr/sbin/smartctl, /usr/sbin/wipefs, /sbin/mkfs.*, /usr/bin/dd
  4. {{ _('Install required tools') }} on remote system: 
    sudo apt install smartmontools parted e2fsprogs xfsprogs dosfstools
