How the scan works

  • Servers (Debian, Ubuntu, Raspberry Pi OS, Proxmox VE and Backup Server, TrueNAS SCALE, Alpine, Rocky Linux, AlmaLinux): FleetPilot reads the list of installed packages over SSH and looks it up in the distribution's security data on OSV.dev. A fix is available when the distribution has published a fixed package; install it with an update from Hosts.
  • Docker containers on those servers: their images are scanned with Trivy if it is installed on the server.
  • pfSense and OPNsense: their own pkg audit.
  • FleetPilot: its Python packages and the machine it runs on.
  • Windows, FRITZ!OS and OpenWrt have no package-level vulnerability data; keep them updated from Hosts and Routers.

Only package names and versions are sent to {{ osv_api }}; no addresses, host names or other data. In offline mode nothing is sent.
