How the proxy works{% if is_admin %}Configure services{% endif %}
1. One addressUsers open FleetPilot at http://192.168.1.100/ or fleetpilot.local. The Raspberry Pi owns this address.
2. Default routeRequests to / go to FleetPilot. Existing FleetPilot pages therefore continue to work normally.
3. Add a service pathIn Proxy Services, add a unique path such as /immich, its internal server address and port, plus a health path.
4. Open the serviceHAProxy validates and reloads the route. Users then open http://192.168.1.100/immich. The backend receives the same path and must support that subpath.
