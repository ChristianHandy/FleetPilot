Screen readers and keyboard

These work all the time and need no setting:

  • Press Tab on any page and choose Skip to content to jump past the menu.
  • Every page has one main heading, the menu is a navigation landmark, and menu groups announce whether they are open.
  • Messages that appear after an action (saved, failed, started) are read out automatically.
  • All buttons and fields have names, including buttons that only show an icon.
  • On the Home page, use Customize and then the Move up and Move down buttons to reorder cards without a mouse.

Tested with keyboard only and with the axe accessibility checker. Report anything that does not work with your screen reader so it can be fixed.
